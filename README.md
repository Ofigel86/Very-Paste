# Very-Paste

## Offset updates

This branch includes an offset snapshot header at:

```text
velocity-cs2/project/protection/cs2_dumper_offsets.hpp
```

The file is generated by `tools/update_offsets.py` and is intentionally limited to the offsets/interfaces/buttons used by the project.

### Preferred workflow with simv0lofficial/cs2_dumper

1. Build and run [`simv0lofficial/cs2_dumper`](https://github.com/simv0lofficial/cs2_dumper) on Windows while CS2 is open.
2. Let it create its `output/` directory.
3. From this repository, run:

```bash
python tools/update_offsets.py --source-dir path/to/cs2_dumper/output
```

Expected files in that output directory:

- `offsets.hpp`
- `buttons.hpp`
- `interfaces.hpp`
- `info.json` optional, but recommended for the CS2 build number

### Remote fallback

If no `--source-dir` is provided, the updater tries public raw output locations:

```bash
python tools/update_offsets.py
```

You can force a custom raw base URL:

```bash
python tools/update_offsets.py --base-url https://raw.githubusercontent.com/<owner>/<repo>/<branch>/output
```

### CI/check mode

To fail when the checked-in generated header is stale:

```bash
python tools/update_offsets.py --source-dir path/to/output --check
```

## Build notes

This is a Windows/MSVC project. Use Visual Studio with the `Development|x64` or `Release|x64` configuration. The Linux sandbox used for Arena does not include MSBuild or the Windows SDK, so only non-MSVC validation can be run there.
